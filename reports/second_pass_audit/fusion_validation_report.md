# SPECTRA-X: FUSION-X Multimodal Ranking & Co-Pilot Validation Report

## 1. Executive Summary & Scoring Architecture

**SCIENTIFIC READINESS STATUS FOR FUSION-X**: **`PIPELINE IMPLEMENTED / HEURISTIC CO-PILOT FUNCTIONAL / SUPERVISED PROBABILISTIC CALIBRATION PENDING`**.

### Scientific Audit of Scoring Logic:
1. **Heuristic vs Probability Distinction**: The priority score generated by `FusionRanker` is strictly a **heuristic weighted ensemble score**, NOT a Bayesian posterior or calibrated probability. In accordance with scientific standards, it must **never be presented to astronomers as a true probability**.
2. **Manually Assigned Heuristic Weights**: In the current implementation, candidates are evaluated across six normalized input features:
   - Spatial Anomaly Score ($S_{\text{spatial}}$) from ASTROVISION
   - Spectral Outlier Score ($S_{\text{spectral}}$) from SPECTRA
   - Temporal Significance ($S_{\text{temporal}}$) from CHRONOS-X
   - Astrometric Match Indicator (Known Star = 1.0, else 0.0) from Gaia DR3
   - Moving Object Indicator (Known Asteroid = 1.0, else 0.0) from Horizons/SBDB
   - Optical Transient Match (Known Transient = 1.0, else 0.0) from ZTF BTS
3. **Absence of Supervised Training Ground Truth**: There is currently no labeled multi-modal training set combining real SPHEREx infrared transients, known asteroids, and anomalies. Therefore, **supervised classification performance (e.g. supervised Precision/Recall) cannot be claimed**.

The human-AI co-pilot classification logic in `FusionRanker.classify_candidate()` was tested against 5 deterministic benchmark scenarios:

### Key Observations from Co-Pilot Audit:
- **Strengths**: Deterministic rule tags successfully separate known optical transients (`CONFIRMED_OPTICAL_TRANSIENT`) and known moving objects (`CONFIRMED_SOLAR_SYSTEM_OBJECT`) from unclassified candidates.
- **Critical Vulnerability Identified**: Instrumental bad pixels that leak through differencing (like the 152.2σ artifact) receive huge temporal scores ($> 20\sigma$) and high spatial reconstruction error, causing the heuristic ranker to score them with maximum priority (`HIGH_TEMPORAL_SIGNIFICANCE` / `POTENTIAL_INFRARED_TRANSIENT`)! Without upstream defect screening (Task 4 & 5), false artifacts dominate the top of the co-pilot discovery queue.

## 3. Robustness to Missing Modalities

- When an observation lacks spectral coverage (e.g. only 1 detector available), $S_{\text{spectral}}$ defaults to 0.0.
- When an observation has no temporal repeat visit, $S_{\text{temporal}}$ defaults to 0.0.
- **Recommendation**: Implement an explicit missing-modality mask in Phase 2 so that missing data is marked `MODALITY_UNAVAILABLE` rather than scored as zero anomaly.
