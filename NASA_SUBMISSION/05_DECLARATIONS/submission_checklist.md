---

## 1. Project Eligibility & Repository Checklist

- [ ] **Public Repository:** The GitHub repository is configured as **Public** and accessible without authentication or private permissions.
- [ ] **Open Source License:** An approved open-source license (e.g., MIT, Apache 2.0) is included in the root directory (`LICENSE`).
- [ ] **Clean Codebase:** No private API keys, user tokens, hardcoded passwords, or unauthorized proprietary assets are present in the committed code.
- [ ] **Readme Documentation:** The root `README.md` provides clear project description, system architecture, installation steps, and run instructions.

---

## 2. NASA Data & Space Agency Compliance

- [ ] **NASA Data Usage:** Project demonstrates meaningful use of NASA resources (NASA SPHEREx Level-2 data formats/models, IPAC archives).
- [ ] **Proper Attribution:** NASA, JPL, IPAC, and other agency missions (ESA Gaia) are explicitly credited in documentation and citations.
- [ ] **Scientific Integrity:** Apparent motion claims clearly distinguish intra-visit dither baselines from real multi-day orbital baselines.
- [ ] **Dataset Distinctions:** The optional personal test dataset is explicitly identified as verification/engineering data, not claimed as new astronomical discoveries.

---

## 3. Artificial Intelligence & Attribution Checklist

- [ ] **AI Disclosure:** The use of AI assistants (Google Gemini / Antigravity, OpenAI ChatGPT) and machine learning models (ASTROVISION, SPECTRA) is transparently disclosed in `NASA_SUBMISSION/04_AI_AND_REFERENCES/ai_tools_disclosure.md`.
- [ ] **Originality:** Human authorship and engineering review of code, logic, and scientific methods are documented.

---

## 4. Media & Deliverables Checklist

- [ ] **Demonstration Video:** 30-second to 2-minute demonstration video has been recorded, uploaded to YouTube/Vimeo/Google Drive, and the link added to project submission.
- [ ] **Executive Summary:** Project summary (under 4 sentences) accurately reflects the final product capability.
- [ ] **Live Demo / Screenshots:** High-resolution screenshots or a deployed live demo URL are added to the project portal page.
