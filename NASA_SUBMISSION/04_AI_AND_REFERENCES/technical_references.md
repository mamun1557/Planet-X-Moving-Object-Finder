# Technical & Open-Source Software References

SPECTRA-X is built entirely upon established, open-source scientific software libraries and modern web development standards.

---

## 1. Core Scientific & Astronomical Computing

- **Astropy Project:**  
  *Astropy: A community Python library for astronomy.*  
  Astropy Collaboration et al. (2022). *The Astrophysical Journal*, 935(2), 167.  
  *Used for FITS I/O, World Coordinate Systems (WCS), and coordinate conversions.*
- **NumPy:**  
  *Array programming with NumPy.*  
  Harris, C. R., et al. (2020). *Nature*, 585, 357–362.  
  *High-performance multidimensional array manipulations and linear algebra.*
- **SciPy:**  
  *SciPy 1.0: Fundamental Algorithms for Scientific Computing in Python.*  
  Virtanen, P., et al. (2020). *Nature Methods*, 17, 261–272.  
  *Optimization, interpolation, and spatial KD-Tree querying.*
- **PyTorch:**  
  *PyTorch: An Imperative Style, High-Performance Deep Learning Library.*  
  Paszke, A., et al. (2019). *Advances in Neural Information Processing Systems (NeurIPS 32)*.  
  *Neural network architecture design and tensor execution for ASTROVISION and SPECTRA.*

## 2. Web Application Frameworks & Interfaces

- **FastAPI:**  
  Modern, high-performance web framework for building APIs with Python 3.10+ based on standard Python type hints.  
  *Used for asynchronous session isolation and analysis endpoints.*
- **React 18:**  
  Declarative component library for building modern user interfaces.  
  *Drives the interactive Observatory, Blink Comparator, and SED Viewer.*
- **Vite:**  
  Next-generation frontend tooling offering fast Hot Module Replacement (HMR) and optimized Rollup production builds.
- **Tailwind CSS:**  
  Utility-first CSS framework for responsive design, custom palettes, and cosmic theme consistency.
- **Lucide React:**  
  Clean, consistent astronomical and interface icon library.
