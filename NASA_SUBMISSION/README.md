## Submission Package Directory Structure

This directory contains all standardized, copy-ready documentation prepared for submission to the official NASA Space Apps Challenge portal.

```
NASA_SUBMISSION/
├── 01_PROJECT/
│   ├── project_summary.md              # 2–4 sentence executive summary
│   └── project_details.md              # In-depth system architecture, users, modules & workflow
├── 02_PROJECT_LINKS/
│   ├── project_links.md                # Canonical URLs, repo link, and deployment status tags
│   └── link_verification.md            # Local verification details and reproduction steps
├── 03_DATA_USED/
│   ├── nasa_datasets.md                # NASA SPHEREx Level-2 FITS, IPAC archive, and dither safeguards
│   ├── other_space_agencies.md         # ESA Gaia DR3 astrometric catalogue integration
│   └── external_datasets_and_apis.md   # 2MASS, ALLWISE, and Astropy WCS libraries
├── 04_AI_AND_REFERENCES/
│   ├── ai_tools_disclosure.md          # Transparent disclosure of embedded ML and AI assistants
│   ├── research_papers.md              # SPHEREx, Batygin & Brown, Gaia, and photometric literature
│   └── technical_references.md         # Open-source libraries and frameworks
├── 05_DECLARATIONS/
│   └── submission_checklist.md         # Action checklist for team review before final portal entry
└── README.md                           # This master guide
```

---

## Instructions for Submission Author

1. Open `01_PROJECT/project_summary.md` and copy the text directly into the "Project Summary" field on the Space Apps portal.
2. Open `01_PROJECT/project_details.md` and copy sections into the corresponding "Detailed Description / How It Works" fields.
3. Review `02_PROJECT_LINKS/project_links.md` and ensure your video link and repository URL match your submission.
4. Paste relevant sections from `03_DATA_USED/` into the "Space Agency Data" section.
5. Review and complete the verification items in `05_DECLARATIONS/submission_checklist.md`.
